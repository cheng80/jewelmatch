# 운영 대시보드 자동 로그인

운영 반영 완료: https://stomematch-dashboard.pages.dev/

- 같은 PC의 같은 브라우저 프로필에서 토큰과 이메일을 localStorage에 저장하고, 새로고침/새 탭에서 서버 auth-refresh 확인 후 로그인 복원. 비밀번호는 저장하지 않음.
- 로그아웃/인증 거절은 저장값 삭제와 다중 탭 로그아웃. 네트워크 장애 시 저장값 보존과 비밀번호 없는 재시도.
- 전체 테스트 86개, 빌드, diff 검사 통과. 에고 로컬에서 새로고침/새 탭, 만료, 다중 탭 로그아웃, 네트워크 재시도 확인.
- 에고 실제 운영 로그인과 저장/새로고침 복원 확인. 현재 브라우저에 로그인 상태 저장 완료.
- 운영 공개 4파일 HTTP200 및 로컬 dist 해시 일치. 직접 Pages 배포 완료, Git 커밋/push는 수행하지 않음.
- 인증 만료/서버 철회, 저장값 삭제, 다른 브라우저/프로필에서는 재로그인이 필요함.
