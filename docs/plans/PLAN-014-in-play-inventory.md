# PLAN-014 플레이 중 인벤토리 교환

- 상태: IN_PROGRESS (게시와 NAS 배포 검증)
- 날짜: 2026-10-01
- 요청: Orca 워크트리에서 레벨 모드 플레이 중 장착 교환 구현, 헤드리스 화면 2장 제공

## 계약

- 하단 패널을 얇게 줄이고 4개 아이템 슬롯과 40px 둥근 사각형 인벤토리 버튼을 한 줄로 정렬한다. 가방 아이콘은 유지하고 청회색 배경과 일반 버튼과 같은 금색 테두리, 8px 모서리로 원형 아이템 슬롯과 구별한다. 버튼 앞 얇은 세로 구분선으로 사용/장착 편집 기능을 구별한다. 아이템 줄 높이는 유지하며 좁은 화면에서는 간격과 슬롯 크기를 가로 너비에 맞춘다. 상단 버튼과 게임 규칙은 유지한다.
- 보드가 idle이며 입력 잠금, 시작 낙하, 특수 연출이 없을 때만 연다. 아이템 타깃 선택은 소모 없이 취소한다.
- 열면 엔진, 타이머, 보드 입력과 BGM을 멈추고 보드를 불투명 배경으로 가린다.
- 기존 StageInventory의 장착 편집안을 재사용한다. 적용은 현재 장착과 다음 레벨 장착에 반영, 취소와 뒤로가기는 기존 장착 유지 후 재개한다.
- 잠긴 슬롯, 보유 수량, 중복 장착 제한, 실제 사용 시 소모, 클리어 보상과 기존 결과창 인벤토리 흐름을 유지한다.
- 백그라운드에서 닫으면 자동 플레이 대신 PauseMenu로 복귀한다. 중복 닫기와 재시작 뒤 콜백은 상태를 바꾸지 않는다.
