# ADR-002 — 진행 랭킹은 완료 레벨 수

- Status: Accepted
- Date: 2026-08-09

## Context
레벨 모드 HUD는 현재 진입 레벨을 보여 준다. 이 값을 그대로 제출하면 레벨 1 미플레이도 1로 올라가거나, 레벨 4 진입이 4위로 저장된다.

## Decision
제출값은 완료한 레벨 수다. 레벨 4 진입은 3. 완료가 없는 레벨 1은 0이며 제출하지 않는다. score<=0 공통 가드와 맞춘다. 제출 시작 후 화면 이동은 완료를 기다린다. 서버 실패는 나가기를 막지 않는다.

## Alternatives Considered
- 대안 A: 현재 진입 레벨 제출
- 대안 B: 최고 도달 레벨만 로컬 저장, 서버 없음

## Reason
아케이드 보드의 "깬 판 수"와 같다. 0점/0레벨 오염을 막는다. 서버 없이도 플레이해야 하는 웹 제약을 지킨다.

## Consequences
- 장점: 랭킹과 HUD 숫자가 어긋나도 계약이 한 줄이다
- 단점/비용: HUD 레벨과 제출값이 1 차이. 문서/에이전트 규칙에 반복 고지가 필요
- 후속 영향: RankingNotifier, pause/timeup 나가기, intoss 레벨 리더보드도 같은 값
