# ADR-008 — 게임 방향: Bejeweled Blitz식 60초 점수 경쟁을 지금 방식으로 다시 만든다

- Status: Accepted (2026-09-24 사용자 승인, D1~D6 권장안 채택)
- Date: 2026-09-23

## Context
Stone Match는 Bejeweled 3 계열 규칙(4일렬 bomb, T/L star, 5일렬 hyper, 6개 이상 supernova) 위에 특수 보석 탭 발동과 스왑 조합 비활성(ADR-001)을 얹은 8×8 매치 3다. "요즘 유행하는 매치 3와 다르다"는 문제 제기에서 개선 방향을 조사했다.

검토한 두 축은 다음과 같다.

- 요즘 사가형(Royal Match, Candy Crush, Homescapes): 이동 횟수 제한 레벨, 수집과 장애물 목표, 특수 보석 교환 조합, 연승 보상, 사람이 설계한 레벨 수천 개와 라이브 운영.
- Bejeweled 원형(Bejeweled 3, Bejeweled Blitz): 빠른 판단, 실력 점수 경쟁, 1분 안팎의 짧은 판, 큰 연쇄, 생명과 대기 시간 없음.

제약:

- 보드는 무작위 생성이고 레벨 데이터 파이프라인이 없다. 팀 규모가 작다.
- 미출시라 외부 사용 지표가 없다. 2026-09-23 코드 확인 기준 GA4, Firebase Analytics, 내부 이벤트 로거가 모두 없다.
- 레벨 모드와 타임 모드는 같은 60초 판(FR-004, FR-005)을 쓴다. 아이템, 클리어 보상, 보상형 광고 2곳, 앱인토스 공식 리더보드는 모두 레벨 모드에 묶여 있다.

조사 근거와 출처는 [01_PRODUCT_SPEC.md](../01_PRODUCT_SPEC.md)의 "게임 방향 기획" 절에 둔다.

## Decision
제안 내용이다. Accepted 전까지 현재 규칙(ADR-001 등)이 유효하다.

1. 게임의 정체성은 Bejeweled Blitz식 60초 점수 경쟁이다. Bejeweled 3의 구조를 통째로 복원하지 않고, 요즘 사가형도 따라가지 않는다.
2. 모드 역할을 나눈다.
   - 두 모드 공통: 60초 판의 손맛을 먼저 개선한다(하이퍼 큐브 교환, Speed Bonus, Last Hurrah, 시간 보상 조정).
   - 타임 모드: 게임의 얼굴이자 실력 경쟁 모드. 구매 아이템은 쓰지 않는다.
   - 레벨 모드: 진행과 수익 모드. 아이템, 클리어 보상, 보상형 광고, 이후 재화를 여기에 둔다.
   - 무한 모드: 유지한다. Zen처럼 시간 제한 없는 휴식 모드로 두고 장기 목표에 연결한다.
3. 재화보다 재화 없는 장기 목표(누적 랭크, 배지, 기록)를 먼저 넣는다. 재화는 이후 코인 1종으로 시작하고 랭킹 모드와 분리한다.
4. 특수 보석 발동은 탭을 유지한다. Bejeweled 3 원형은 매치 발동이지만, 요즘 모바일(Royal Match)은 탭 발동을 쓰므로 현재 방식이 지금에 맞다.

세부 규칙과 수치, 미결정 사항(D1~D10)은 Product Spec "게임 방향 기획" 절, 구현 단계는 [PLAN-005](../plans/PLAN-005-blitz-modernized-direction.md)를 따른다.

## Alternatives Considered
- 대안 A: 요즘 사가형으로 전환. 이동 횟수 레벨, 장애물, 교환 조합, 연승 보상. 레벨 설계와 운영 비용이 크고, 상위 2개 게임이 장르 매출의 절반가량을 가져가는 시장에서 차별점이 없다. Bejeweled Stars가 같은 시도를 했고 커뮤니티 평가는 "복사본의 복사본"이었다.
- 대안 B: Bejeweled 3 구조 복원. 모드 8개, 비밀 모드 해금, 끝나는 Classic, 매치 발동, 숨긴 보석 효과. 한 번 사면 끝인 2010년 PC 패키지용 구조라 짧게 들어오는 무료 모바일 사용자에게 선택지와 진입 장벽이 과하다. 이 구조를 무료 모바일로 옮긴 Bejeweled Classic은 광고와 모드별 횟수 제한으로 가장 많은 불만을 받았다.
- 대안 C: 현재 상태 유지. 타이머 기반 모드 2개와 무한 모드가 비슷한 무게로 공존하고, 판 안의 실력 표현 장치와 장기 목표가 없다.

## Reason
- Bejeweled에서 지금도 통하는 부분은 빠른 판단과 실력 점수 경쟁이다. Blitz는 Facebook이라는 소셜 플랫폼에서 1분 점수 경쟁과 친구 순위표로 성공했다. 스토어 설명 기준 1억 2500만 명 이상이 플레이했다.
- Stone Match의 조건이 Blitz와 가깝다. 토스 미니앱이라는 소셜 플랫폼, 이미 있는 60초 모드와 랭킹, 무작위 보드 엔진이 그렇다.
- 무작위 보드는 레벨 콘텐츠 없이 점수 경쟁을 무한히 제공한다. 일일 동일 보드와 주간 순위 같은 요즘 경쟁 형식을 붙이기 쉽다.
- 커뮤니티 불만은 생명, 대기, 모드별 횟수 제한, 강제 광고, 운에 기대는 사가 후반에 집중된다. 이를 피하는 것 자체가 차별점이다.
- 두 타이머 모드가 같은 60초 판을 쓰므로, 공통 코어 개선이 두 모드와 기존 수익 구조를 함께 강화한다.

## Consequences
- 장점: 콘텐츠 제작 비용이 작다. 랭킹의 공정성과 수익화가 모드 단위로 분리된다. 현재 광고 정책(ADR-003)과 충돌하지 않는다.
- 단점/비용: 사가형 사용자의 진행 기대를 레벨 모드만으로 충족해야 한다. 실력 경쟁 모드는 초보자 이탈 위험이 있다. 지표가 없어 초기 판단이 추론에 기댄다.
- 후속 영향:
  - 하이퍼 큐브 교환을 채택하면 ADR-001을 부분 개정(Superseded 표시 또는 개정 절 추가)하고 BR-022, FR-002, 힌트와 NoMoves 규칙을 바꾼다.
  - Last Hurrah를 채택하면 ADR-007과 BR-093의 TimeUp 제출 시점, 1900ms 버튼 활성 계약을 바꾼다.
  - 앱인토스 공식 리더보드 대상을 타임 점수로 바꾸면 FR-009와 스토어 등록 문구를 바꾼다. ADR-002(진행 랭킹 = 완료 레벨 수)는 서버 랭킹에서 유지할 수 있다.
  - Speed Bonus를 레벨 모드에도 적용하면 ADR-006과 BR-040 목표 점수를 재조정한다.
  - 타임 랭킹 점수 규모가 바뀌면 기존 기록 처리(초기화 여부)를 정한다. 운영 랭킹 초기화는 승인, 백업, dry-run 절차를 따른다.
