## 운영 경계

- 신규 앱 빌드와 서버 기능은 PocketBase만 사용한다. Supabase SDK/CLI/프로젝트 연결은 게임 실행이나 빌드에 필요하지 않다.
- 과거 SQL, 읽기 전용 스냅샷 가져오기 도구와 원본 서비스 보존은 실행 의존성이 아니다. 원본 서비스 삭제와 기존 브라우저 탭 강제 종료는 별도 작업이다.
- 현재 미커밋 사용자 오디오 변경을 보존한다. 이번 작업에서 새 커밋/push/PR은 수행하지 않는다.
- 병렬 작업은 Orca CLI로 조정하고 브라우저는 ego CLI 배경 작업만 사용한다.
