## Instruments 확인과 분석 차단

- USB connected/paired, Developer Mode Enabled, DDI compatible/usable 확인. CLI 목록은 Offline/Devices 사이에서 달랐고, 첫5초 기록은 `Timed out waiting for device to boot`로 실패했다.
- Xcode27.0 Device Hub와 Instruments 앱을 열고 실제 iPhone/All Processes를 선택한 뒤 Animation Hitches30초 기록은 진행됐다. UI에31초 Run1과 후처리 상태가 나타났으며 원시 `trace-data.atrc` 3,666,910,720바이트가 생성됐다. GUI 경로가 기록까지 진행된 이유를 CLI 문제의 확정 원인으로 해석하지 않는다.
- 후처리 중 Mac 가용 공간103MiB, Instruments 프로세스 종료, 화면 캡처/로그 조회의 자원 부족 실패를 확인했다. 시작 전 디스크 기준값이 없어 전체 저장 공간 부족을 이번 기록만의 원인으로 단정하지 않는다.
- 이번 GUI 실행이 만든 분석 캐시 약3.1GiB만 제거했다. 원본을 보존한 채 Hangs 데이터만 추출하려 했으나 임시 데이터가6GiB 이상 증가해 디스크 고갈 직전 중단했다. 이 실행의 임시 데이터도 제거했다. 이전 추적과 다른 프로젝트 파일은 정리하지 않았다.
- 따라서 Hitches/Hangs 건수,100ms 이상 이벤트 수,CPU/GC/GPU/프로세스별 분석 결과는 없음. 성능 수치는 게임 내부 패널 기준이다. 원시 기록 생성과 분석 완료를 구분한다.
